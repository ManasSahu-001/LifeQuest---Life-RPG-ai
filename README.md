## 🌟 Executive Overview

**LifeQuest** is a production-grade, full-stack Gamified Productivity RPG and Metropolitan City-Building platform. It transforms real-life ambitions, study regimens, coding projects, and fitness routines into an immersive, story-driven gaming odyssey.

By fusing an **intelligent AI Quest Master**, a **server-authoritative progression engine**, **8 level-locked interdimensional visual realms**, **real-time boss arena battles**, an **urban district builder**, a **Treasury economy**, and a **zero-asset procedural Web Audio synthesizer**, LifeQuest ensures that every single daily task conquered in the real world fuels permanent digital progression.

> [!TIP]
> **Zero Sound Files Required**: LifeQuest contains a built-in procedural synthesizer that crafts rich harmonic chords, arpeggiated synth leads, and resonant Taiko/Castle drums on-the-fly using the browser's native **Web Audio API**. No audio assets to download, zero latency, and zero bandwidth overhead!

## 🎵 2. Zero-Asset Procedural Web Audio Engine

LifeQuest features a state-of-the-art **Web Audio API Synthesizer** (`audioEngine.ts`) engineered to deliver high-volume, studio-grade soundscapes and punchy combat SFX without relying on static `.mp3` or `.wav` asset downloads.

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                      LIFEQUEST WEB AUDIO SYNTHESIZER                        │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  [ Oscillators: Sawtooth / Triangle / Sine ] ──┐                            │
│  [ Sub-Bass Generators: 73Hz / 146Hz ] ───────┼──> [ Low-Pass BiquadFilter ]│
│  [ 16th-Note Arpeggiator Sequencers ] ────────┘           │                 │
│                                                           ▼ (Modulated)     │
│  [ LFO: 0.12Hz - 0.25Hz Frequency Sweep ] ────────────────┘                 │
│                                                           │                 │
│  [ BGM Gain Node ] ──┐                                    ▼                 │
│  [ SFX Gain Node ] ──┴──> [ Master Gain (2.0x) ] ──> [ DynamicsCompressor ] │
│                                                      (Studio Mastering)     │
│                                                              │              │
│                                                              ▼              │
│                                                    [ AudioDestination ]     │
│                                                    (Laptop / Headphones)    │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 🎛️ Audio Engine Architecture
1. **Studio Mastering Limiter (`DynamicsCompressorNode`)**:
   - Compresses dynamic range to maximize loudness and punch across laptop speakers and headphones:
   - `threshold`: `-12 dB` | `knee`: `20` | `ratio`: `3.5:1` | `attack`: `0.003s` | `release`: `0.18s`.
2. **Dual-Stage Gain Hierarchy**:
   - Master Gain calibrated with linear ramping to prevent audio popping.
   - Independent volume sliders for ambient BGM and combat sound effects.
3. **Adaptive Procedural Soundscapes for All 8 Realms**:

| Realm | Musical Mode / Scale | Synthesis Technique | Harmonic Profile |
|---|---|---|---|
| **Theme A: Cyberpunk** | D Minor Synthwave | Poly-saw pad + 16th-note arp | Sub-Bass (73Hz/146Hz) + 2.2kHz LFO modulated filter |
| **Theme B: High Fantasy** | D Celtic Dorian | Ringing harp arpeggios | Acoustic fifths (D2, A2, D3, F#3, A3, D4) + warm drone |
| **Theme C: Solarpunk** | F Major 9 Ambient | Crystal sine bells + solar drone | Resonant air frequencies (87Hz–523Hz) + marimba chime |
| **Theme D: Enchanted Forest** | G Pentatonic Folk | Soft triangle chords + wind bells | Shimmering 1.3kHz high bells with long exponential decay |
| **Theme E: Last Samurai** | Japanese Insen Scale | Koto plucks & Taiko resonant drum | Percussive sine drop (140Hz ➔ 35Hz) + traditional plucks |
| **Theme F: City Builder** | Industrial Pulse | Steady construction rhythm | Metallic square wave harmonics & driving electro bass |
| **Theme G: Haunted World** | C Harmonic Minor | Gothic crypt pipe organ | Dual-sawtooth organ drone (65Hz–261Hz) + spectral graveyard bells |
| **Theme H: The Upside Down** | Detuned '80s Darkwave | Detuned dual-oscillator pitch drift | Sub-rumble (45Hz) + 900Hz low-pass sweep & creepy pulse |

### 💥 Metagame & Combat Sound Effects

- **Critical Strike**: Multi-frequency chord blast with high-resonance shimmer.

## 🧮 5. Server-Authoritative Progression Math

All character calculations occur inside atomic database transactions on the backend. The client never calculates or dictates awards.

### 1. Nonlinear Leveling Formula
The experience points required to reach the next character level scale exponentially:

$$\text{requiredXP}(\text{level}) = \lfloor \text{baseXP} \times \text{growthFactor}^{(\text{level} - 1)} \rfloor$$

* $\text{baseXP} = 100$
* $\text{growthFactor} = 1.25$
* Surplus XP earned from high-tier boss quests overflows deterministically across multiple levels.

### 2. Habit Streak Multiplier Engine
Consecutive days of quest completion trigger compounding multipliers:

| Streak Range | Multiplier Bonus | Extra Perk |
|---|---|---|
| **1 – 2 Days** | **1.0x** (Base Rewards) | Standard City Growth |
| **3 – 6 Days** | **1.2x** (+20% XP & Gold) | Particle Glow on Avatar |
| **7 – 13 Days** | **1.5x** (+50% XP & Gold) | Boss Strike Damage Bonus (+15%) |
| **14+ Days** | **2.0x** (Double Rewards) | Legendary City Shield Active |

### 3. Server-Calculated Boss Strike Damage
$$\text{Damage} = \lfloor (\text{Strength} \times 2.2) + (\text{Level} \times 5.0) + \text{RandomVariance}(-3, +5) \rfloor$$

## ⚡ 7. Local Development Quickstart

### Prerequisites
- **Node.js 20 LTS** or higher installed.
- **npm** (v10+) installed.

### 1. Clone & Install
```bash
git clone https://github.com/ManasSahu-001/LifeQuest---Life-RPG-ai.git
cd LifeQuest---Life-RPG-ai

# Install root, backend, and frontend dependencies:
npm run install:all
```

### 2. Start Development Servers
```bash
# Run both Backend (Port 5000) and Frontend (Port 5173) simultaneously:
npm run dev:all

# Or start services individually in separate terminals:
npm run dev:backend   # Express API server with TSX hot-reloading
npm run dev:frontend  # Vite frontend client with HMR
```

### 3. Build & Run Automated Verification Suite
```bash
# Compile and build both client and server:
npm run build

# Run comprehensive test suite (ACID transactions, level lock, rate limiters):
npm run test
```

## 🚀 8. Production Cloud Deployment

### 🌐 Frontend on Vercel
1. Import repository on [Vercel](https://vercel.com).
2. Set **Root Directory** to `frontend`.
3. Add Environment Variable:
   - `VITE_API_URL`: `https://lifequest-backend-xyoe.onrender.com`
4. Deploy! Client routing is handled by `frontend/vercel.json`.

### ⚙️ Backend on Render
1. Create a Web Service from the repository on [Render](https://dashboard.render.com).
2. Set **Root Directory** to `backend`.
3. Build Command: `npm install && npm run build`
4. Start Command: `npm start`
5. Configure Environment Variables:
   - `NODE_ENV`: `production`
   - `PORT`: `10000`
   - `JWT_SECRET`: `your_secure_jwt_secret_key`
   - `DATABASE_URL`: `postgresql://user:pass@host:5432/dbname` (e.g. from [Neon.tech](https://neon.tech))

> [!NOTE]
> **24/7 Keep-Alive Auto-Pinger**: The backend (`server.ts`) includes an integrated background keep-alive service that pings its own `/health` endpoint every 8 minutes, preventing cloud sleep cycles!

## 🛡️ 9. Security & Hardening Features

- **Sliding-Window Rate Limiting**:
  - `authRateLimiter`: Maximum 20 requests per 15 minutes on login/signup.
  - `campaignRateLimiter`: Maximum 10 requests per 10 minutes on AI generation.
  - `apiRateLimiter`: General traffic guard across all routes.
- **Memory-Guarded Production Build**: Node options configured with `--max-old-space-size=384` to ensure rock-solid stability within 512MB RAM cloud environments.
- **Information Disclosure Prevention**: Production error handlers mask database paths and internal stack traces.
